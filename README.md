### Hello, I'm itsrizzgg11 👋

I'm a developer who spends way too much time reading processor manuals and rewriting things in Rust that probably didn't need rewriting. Most of what I build lives in the terminal — fast, small, and quietly opinionated tools that scratch an itch I couldn't reach with existing software.
